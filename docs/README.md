# Клавиши. — Keyboard Choice Lab v1.4

Помощник выбора музыкальных клавиш с акцентом на реальные сценарии игры, индивидуальные редакционные карточки, честные компромиссы и первый музыкальный сеанс.

## Основное

- Сайт на статических файлах, без бэкенда, авторизации и базы.
- 80 моделей с официальными ссылками на характеристики и редакционными полями `editorial`: `best_for`, `not_for`, `try_in_store`, `question`, опционально `data_warning`.
- Возможность выбрать сценарий, размер клавиш, необходимость звука без ПК и ограничения.
- Отдельно различаются MIDI, встроенный звук и USB audio.
- Цена указывается только как датированный ориентир, не наличие; строгий бюджет требует свежей проверенной карточки точной модели.
- Выбор двух моделей с текстовым объяснением решающего компромисса.
- Практический маршрут для Reaper и автономного инструмента, чек-листы и магазинный 10-минутный тест.

## Запуск и проверки

Запускай каталог по HTTP, а не через `file://`, поскольку используются ESM-модули и `fetch`:

```sh
python -m http.server 8000 --directory .
```

Открыть `http://localhost:8000/` из папки `docs`.

```sh
npm test
```

Для Cloudflare Workers: Root directory `docs`; пустая команда сборки; Deploy command `npx wrangler deploy`. Репозиторий `onomastika/game`, ветка `keyboard-choice-lab`. Конфигурация находится в `wrangler.jsonc`.

## Политика данных

Исторические цены и технические характеристики — срез от 2026-11-06. Свежесть цены считается по отметке проверки. Источники на уровне каждой модели. Тексты о пригодности — редакционные интерпретации, не результат реального прослушивания; их следует проверять лично в магазине. Настройки хранятся только в браузере.

История 10 итераций: `../CONTENT_ITERATIONS.md` в архиве проекта.

## Каталог v1.3

- Релиз v1.3: 40 моделей (после начальной базы из 11); релиз v1.4: 80 моделей.
- Бренды и типы инструментов фильтруются отдельно; поиск по названию сохранён.
- Собственные звуки отделены от встроенных динамиков и USB audio; рабочие станции без колонок больше не называются MIDI-контроллерами.
- Цена и наличие 29 новых моделей во Вьетнаме не заявляются подтверждёнными: `prices: []`.
- Отсутствующие точные спецификации `null` и требуют дополнительной проверки.

## Расширение v1.4 и годы выпуска

- Два поля по смыслу: `release_year` (год первой публикации / выхода модели) и `release_year_evidence` (ссылка на датированный источник), плюс `release_year_status` (`sourced`/`unknown`).
- 80 моделей, 11 производителей. Два неподтверждённых года не подменяются догадками.
- Год виден в рекомендациях, списке, подробностях и сравнении. Фильтрация по минимальному году и сортировка новее/старее; неизвестные годы в конце.
- Архивные модели учитываются отдельно: новая дата версии не означает наличия в продаже во Вьетнаме.
- Цены, наличие, гарантия и субъективное ощущение клавиш должны быть проверены перед покупкой; годы не влияют на автоматическую оценку пригодности.
