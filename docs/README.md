# Клавиши. — Keyboard Choice Lab v1.6

Помощник выбора музыкальных клавиш с акцентом на реальные сценарии игры, индивидуальные редакционные карточки, честные компромиссы и первый музыкальный сеанс.

## Основное

- Сайт на статических файлах, без бэкенда, авторизации и базы.
- 124 модели со ссылками на источники характеристик на характеристики и редакционными полями `editorial`: `best_for`, `not_for`, `try_in_store`, `question`, опционально `data_warning`.
- Возможность выбрать сценарий, размер клавиш, необходимость звука без ПК и ограничения.
- Отдельно различаются MIDI, встроенный звук и USB audio.
- Цена указывается только как датированный ориентир, не наличие; строгий бюджет требует свежей проверенной карточки точной модели.
- Выбор двух моделей с текстовым объяснением решающего компромисса.
- Практический маршрут для Reaper и автономного инструмента, чек-листы и магазинный 10-минутный тест.

## Запуск и проверки

Запускай каталог по HTTP, а не через `file://`, поскольку используются ESM-модули и `fetch`:

```sh
python -m http.server 8000 --directory .
```

Открыть `http://localhost:8000/` из папки `docs`.

```sh
npm test
npm run build:offline
```

Автономная версия создаётся как `docs/offline.html` (не отслеживается Git; автоматически генерируется перед `npm test`); открывается без сервера, ESM-импортов и дополнительных файлов. Собирается из тех же `catalog.json`, `engine.js`, `app.js`, `styles.css`, так что не существует отдельного ручного форка сайта.

Для Cloudflare Workers: Root directory `docs`; пустая команда сборки; Deploy command `npx wrangler deploy`. Репозиторий `onomastika/game`, ветка `keyboard-choice-lab`. Конфигурация находится в `wrangler.jsonc`.

## Политика данных

Исторические цены и большинство технических характеристик — базовый срез от 2026-11-06; углублённая проверка 14 моделей от 2026-11-07. Свежесть цены считается по отметке проверки. Источники на уровне каждой модели. Тексты о пригодности — редакционные интерпретации, не результат реального прослушивания; их следует проверять лично в магазине. Настройки хранятся только в браузере.

История 10 итераций: `CONTENT_ITERATIONS.md`.

- Год виден в рекомендациях, списке, подробностях и сравнении. Фильтрация по минимальному году и сортировка новее/старее; неизвестные годы в конце.

- Изменён смысл условия **«звук без компьютера»**: достаточно собственного звукового генератора. Для игры с ним могут понадобиться наушники либо колонки. Встроенные динамики — отдельная обязательная галочка в дополнительных настройках.
- Добавлены конкретные габариты и aftertouch для Yamaha MONTAGE M6/M7/M8x; исправлены габариты/подключения Roland JUNO-X, Korg NAUTILUS AT 61 и Roland E-X50.

- Сайт не проверяет цены в реальном времени и не имитирует личное тестирование ощущений от клавиш. Внутри проекта `CATALOG_AUDIT_V15.md` — отчёт и методика.

## Улучшение v1.6 (7 ноября 2026)

- Углублены параметры **14 конкретных моделей** по спецификациям производителей: механика, размеры/масса, разъёмы, питание, aftertouch клавиш и пэдов. Для каждого нового поля сохранён `physical_spec_evidence` (ссылка, дата, список проверенных полей). Каталог остаётся на **124 моделях**.
- Новые необязательные **строгие фильтры**: максимум веса, USB audio interface, питание от **AA**, aftertouch **клавиш**. Если производитель не подтверждает параметр, модель попадает в «Проверить», а не считается неподходящей или подходящей.
- Aftertouch клавиш (`key_aftertouch`) и aftertouch пэдов (`pad_aftertouch`) намеренно разделены. Например, у Launchkey 61 MK4 официально подтверждён полифонический aftertouch **пэдов**; это не доказательство наличия aftertouch у клавиш.
- USB audio — интерфейс с возможными разными направлениями потока; если необходима именно запись собственного звука в Reaper, требуется проверить конкретный маршрут сигнала. USB MIDI — другая функция.
- В карточке видно, что проверено, а что нет; различия добавлены в сравнение. Механика клавиатуры — категория, **не оценка качества ощущения**.
- Убрана зависимость рекомендаций от старых/непроверенных цен. Рекомендация не выдаётся за подтверждение наличия в магазине.
- **56 автоматических тестов**; проверка страниц через Chromium заблокирована окружением (ERR_BLOCKED_BY_ADMINISTRATOR) и **не заявляется пройденной**. Статическая/синтаксическая и логическая проверка прошла.

См. `EVIDENCE_AUDIT_V16.md` с полным списком обогащённых моделей и открытыми вопросами.
