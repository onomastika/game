## Принципы достоверности

1. У каждой добавленной модели есть URL страницы производителя.
2. `onboard_sounds` и `speakers` — разные атрибуты. Встроенный звуковой движок без динамиков требует наушники/колонки; это не MIDI-контроллер.
3. `usb_audio` не равно `usb_midi`. Существование аудиоинтерфейса USB не доказывает наличие встроенных звуков (пример — Korg Keystage).
4. Неустановленные размеры, связь и комплектация представлены `null`, а не предполагаемыми значениями.
5. В карточках есть отдельные сценарии применения, ограничения, тест перед покупкой и вопрос, помогающий выбрать.
6. Старые цены на 11 исходных моделей не выданы за актуальные предложения; наличие нужно подтверждать у магазина.

## Интерфейс и тесты

- Фильтры по статусу соответствия, бренду, типу; поиск по названию.
- Показ первых 12 результатов с кнопкой продолжения для 40 моделей.
- 26 тестов модели и контента; браузерные smoke-сценарии для 320/390/768/1440 px.
- Ключевые ограничители не ослабляются: нажатие, мини-клавиши, диапазон, габариты, автономность, жёсткий бюджет.
